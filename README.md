A deterministic make.fun bounty entry for a locally rendered vertical GTA VI Trailer 2 Short. The clip pitches making money on make.fun by making clips with AI.

The finished video is kept outside this repository at `clip/gta6-clipper-01-short.mp4`. YouTube posting is manual. `VIDEO.json` is intentionally absent until the user posts a public Short and provides its real URL; the follow-up run will add it, bundle, and submit.

## Run

```sh
node main.ts
```

The harness copies the bytes in `VIDEO.json` to `/output/VIDEO.json`.
